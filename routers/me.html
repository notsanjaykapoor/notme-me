I am an experienced entrepreneur that loves building software and working in environments where ownership, accountability and empathy are core principles. You can read about my background here or on LinkedIn.

My public code repos are a playground for learning and exploring. These repos can be categorized as general purpose tooling in various languages (Elixir, Python, Ruby) and application specific.

The notme-corpus repo is a RAG app that ingests a list of documents, generates embeddings and stores them in a Qdrant vector database. The user interface allows natural language queries on any ingested corpus. The ingest process supports multimodal datasets, using Qdrant's ability to store multiple vectors in a single point. The app also supports one-shot image captioning. Image datasets use CLIP models, and all queries are run using a local LLM to address security concerns with sensitive data. The app is a Python codebase with a user interface built using Htmx.

The notme-paas repo contains 2 apps, a distributed queue manager and a password manager. This distributed queue solution uses lower cost vps providers (e.g. Hetzner), Nats (a wonderful networking library), and a Postgres work queue to implement a solution that can distribute workloads across multiple machines and auto scale those machines as necessary. The password manager app uses pass and gpg encryption under the hood. It gives users control over their password management using secure, open-source encryption. The app is a Python codebase with a user interface built using Htmx.

The deploybot repo is an ops tool used to build and deploy apps in Kubernetes environments. It's built in Rust and uses PKI to control user access to deployable assets.
