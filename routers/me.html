I am an experienced entrepreneur that loves building software and working in environments where ownership, accountability and empathy are core principles. You can read about my background here or on LinkedIn .

My public code repos are a playground for learning, building, and exploring. These repos can be categorized as general purpose tooling in various languages (Elixir, Python, Ruby) and application specific.

The notme-corpus repo is a RAG app that ingests a list of documents (corpus) into a Qdrant vector database and allows natural language queries on any corpus. All queries are run using a local LLM. The app is a Python codebase with a user interface built using htmx.

The notme-paas repo is a password manager app using pass and gpg encryption. It gives users control over their password management using secure, open-source encryption. The app is a Python codebase with a user interface built using htmx.

The deploybot repo is a tool used to build and deploy apps in Kubernetes environments. It is built in Rust and uses PKI to control access to deployable assets.
